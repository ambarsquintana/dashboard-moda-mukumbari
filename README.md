# Tablero ejecutivo de ventas, rentabilidad y clientes de Moda Mukumbarí

![Status](https://img.shields.io/badge/Status-En%20desarrollo-yellow)

Dar a la Gerencia General una vista única y consolidada en USD de las ventas, la rentabilidad y los clientes, para decidir en qué países, tiendas y categorías invertir, cómo ajustar los descuentos y a qué clientes dirigir acciones de retención.
